Bloco 1 — Gabriel

O adversário — matemática numa página web

Precisamos exibir a dedução completa da fórmula de Bhaskara numa página. Como se escreve uma fração com raiz quadrada dentro em HTML?

  • Imagem (PNG de um editor de equações) Borra no zoom, não é selecionável, não é pesquisável, depende de alt escrito à mão.
  • Biblioteca JavaScript (MathJax, KaTeX) Funciona bem, mas é dependência externa, peso extra e não renderiza sem JS.
  • MathML — markup nativo do próprio HTML É o caminho deste trabalho.

MathML na prática · Gre-Nal5

Bloco 2 — Pedro Henrique Barcellos

Um elemento nativo, como <table> ou <svg>

  • MathML = Mathematical Markup Language, padrão do W3C desde 1998.
  • Descreve a matemática como estrutura, não como desenho: o navegador é quem decide a tipografia, o tamanho do radical, o espaçamento dos operadores.
  • Faz parte do HTML5 — <math> vive no mesmo DOM que o resto da página, sem plugin e sem conversão.
  • Duas vertentes: Presentation MathML — como a fórmula aparece. É o que os navegadores implementam e o que usamos.
    Content MathML — o que a fórmula significa; voltado a sistemas de computação simbólica.
  • MathML Core — o subconjunto enxuto que os navegadores suportam hoje.

Bloco 3 — Gabriel

Os blocos de construção

  • <math> — o contêiner de toda fórmula. display="block" destaca e centraliza; o padrão inline a insere no meio do texto.
  • <mrow> — agrupa: o "parêntese invisível" que mantém a expressão coesa.
  • <mi> identificador — variável, itálico automático.
  • <mn> número  ·  <mo> operador. É a distinção entre eles que faz o navegador aplicar o espaçamento tipográfico correto — sozinho.
  • <mfrac> — fração: exatamente dois filhos, numerador e denominador.
  • <msup> / <msub> — base + expoente, base + índice.
  • <msqrt> — raiz, com o radical desenhado no tamanho certo do conteúdo.
  • <mtext> texto corrido  ·  <mspace> espaço controlado.

Detalhe que faz diferença: entidades

O sinal de menos da matemática não é o hífen do teclado. Usamos entidades numéricas para garantir o caractere certo em qualquer editor e codificação.

&#177;±Mais ou menos — a origem das duas raízes
&#916;ΔDelta maiúsculo — o discriminante

1

Exemplo da página: 2x2−7x+3=0  dá Δ=25, x1=3 e x2=12.

Bloco 5 — Gabriel

Estilizando fórmula com CSS comum

estilo.css

math {
  font-family: var(--serif);
  color: var(--tinta);
}

math[display="block"] {
  font-size: 1.3em;
  margin: 1.4rem 0;
  overflow-x: auto;   /* telas estreitas */
}

@media (prefers-color-scheme: dark) {
  :root { --tinta: #e8e6e1; }
}

@media print {
  .passo { break-inside: avoid; }
}
  • Seletor comum. math { } funciona como qualquer outro seletor CSS.
  • Tema claro/escuro. A fórmula troca de cor junto com a página, via variável CSS.
  • Responsivo. overflow-x: auto deixa a equação rolar em vez de estourar o layout no celular.
  • Impressão. @media print evita quebrar um passo da dedução ao meio.

Bloco 5 — Gabriel · demonstração ao vivo

Três coisas que o adversário não faz

  • Zoom sem perda. Ctrl + + na página: a fórmula é texto vetorial, cresce nítida em qualquer tamanho.
  • Seleção e cópia. Arraste o mouse sobre a fórmula — ela seleciona como texto e vai para a área de transferência.
  • Busca na página. O conteúdo está no DOM, então Ctrl + F encontra.
  • Impressão perfeita. Sem imagem serrilhada: o PDF sai com a fórmula em resolução de texto.

Momento de mostrar no navegador, não no slide.

O leitor de tela lê matemática

Porque a estrutura está no markup, o leitor de tela não lê símbolos soltos: ele lê a expressão como ela é falada.

O que o NVDA / Narrador anuncia

“x igual a fração: menos b mais ou menos raiz quadrada de b ao quadrado menos quatro a c, sobre dois a”

  • Uma imagem entregaria, no melhor caso, um alt escrito à mão — e desatualizado.
  • MathML permite navegar dentro da fórmula: entrar no numerador, ler só o radical.
  • Beneficia também tradução automática, indexação por buscadores e conversão para Braille.
